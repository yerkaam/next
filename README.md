# NXT Predictor — прогноз следующей цены акции Nextracker (NXT.US)

Программа загружает историю цен, сделки последних сессий и новости по компании,
считает признаки, обучает модели и показывает **ожидаемую цену закрытия
следующей торговой сессии**, диапазон и вероятность роста.

> ⚠️ Это статистическая модель, а не инвестиционный совет. Дневные движения акций
> в основном случайны. Смотрите на блок «Насколько модели можно верить» в отчёте.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m nxt_predictor              # реальные данные NXT (нужен интернет)
python -m nxt_predictor --demo       # синтетические данные, без интернета
```

Результат печатается в консоль и сохраняется в `output/`:
- `NXT_report.html` — отчёт с графиком, прогнозом, новостями;
- `NXT_prediction.json` — те же цифры для других программ.

### Параметры

| Флаг | Что делает |
|---|---|
| `--ticker NXT` | тикер (можно любой американский: `--ticker AAPL --company Apple`) |
| `--company Nextracker` | название для поиска новостей |
| `--years 10` | сколько лет истории загрузить (у NXT — вся история с IPO 2023) |
| `--context SPY,QQQ,TAN,...` | рынок и конкуренты как доп. признаки; `none` — отключить |
| `--backtest-days 250` | длина честной проверки на истории |
| `--fast` | без подбора гиперпараметров (секунды вместо ~2–3 минут) |
| `-v` | показывать ход обучения и подобранные параметры |
| `--prices-csv file.csv` | свои дневные цены (`Date,Open,High,Low,Close,Volume`) |
| `--news-csv file.csv` | свои новости (`time,title[,summary]`) |
| `--out output` | папка для отчётов |

## Откуда берутся данные

| Данные | Источник |
|---|---|
| Дневные цены (OHLCV) | Yahoo Finance, при ошибке — Stooq |
| Сделки | 1-минутные бары Yahoo за последние 7 дней (все сделки, агрегированные по минутам) |
| Новости | Yahoo Finance News + Google News RSS |
| Рынок и конкуренты | SPY, QQQ, TAN (солнечный ETF), FSLR, ARRY, SHLS, ENPH |

Бесплатные источники не отдают поштучную ленту сделок (тиковые данные). Если
она нужна, можно подключить платный API (Polygon, Alpaca и т.п.) в
`nxt_predictor/data.py`.

## Как работает модель

1. **Признаки** (`features.py`)
   - технические: доходности за 1–20 дней, отклонение от SMA 5/20/50, RSI, MACD, ATR, волатильность, гэпы;
   - поток сделок: где закрылся день внутри диапазона, аномальный объём, денежный поток, OBV;
   - рынок и конкуренты: их доходности за 1 и 5 дней, относительная сила NXT, бета и корреляция с SPY/TAN;
   - новости: тональность каждого заголовка (VADER + финансовый словарь), среднее/мин/макс за день, число новостей.
     Новость привязывается к последнему торговому дню, на момент которого она уже известна
     (новость после закрытия или в выходные влияет на прогноз следующей сессии).
2. **Подбор гиперпараметров**: для каждой модели перебирается сетка параметров на
   `TimeSeriesSplit` (обучение всегда в прошлом, проверка — в будущем). Подбор идёт
   только на данных *до* периода проверки, чтобы оценка не была завышена.
3. **Ансамбль** (`model.py`): Ridge, GradientBoosting, HistGradientBoosting, RandomForest,
   ExtraTrees предсказывают лог-доходность следующего дня; вес модели ∝ 1/MAE² на валидации.
   Отдельно два классификатора (логистическая регрессия + бустинг) оценивают вероятность роста.
   Квантильный бустинг даёт диапазон 10–90%.
4. **Проверка**: walk-forward на последних 250 днях — модель переобучается каждые 20 дней
   только на прошлом.
   Ошибка сравнивается с наивным прогнозом «цена завтра = цена сегодня».
   Вероятность роста проверяется по Brier score. Отчёт пишет вердикт: полезен прогноз или нет.
   Если модель не лучше наивного прогноза — прогнозу доверять не стоит.
